Trading agents: how one day runs

Paper trading on NSE/BSE. Every trade passes three safety gates before a simulated order is placed.

Data Rule gate AI (Claude) Execution Block / stop

1 · Before market ~08:30–09:15

Scanner
Ranks NIFTY stocks: gaps, volume spikes, breakouts, NR7. Data: NSE Bhavcopy, Yahoo or Google.
Market context
NSE F&O ban list, results & board-meeting dates, RSS headlines.
Watchlist + config ready
Stocks, strategy per stock, capital, risk limits. Warm-up candles loaded (Upstox → Yahoo fallback).
market opens 09:15

2 · Trading loop every 5-min candle

Market data live
Upstox candles. After 3 failures → Kotak Neo quotes built into candles; switches back when Upstox recovers.
Paper broker: manage open trades
Fills pending orders at the candle's open; checks stop-loss and target (gap-aware).
Strategy agent
ORB · EMA crossover · Supertrend → entry or exit signal with a stop-loss.
entry signal
Gate 1 · Event guard
Stock on F&O ban list? Results today?
EVENT_BLOCK
clear
Gate 2 · Risk agent
Size = 1% risk, rounded to lots. Margin, entry window 09:20–15:00, max positions/trades, order-rate cap.
RISK_BLOCK
approved + quantity
Gate 3 · AI analyst optional
Claude reads price action, NSE events, headlines, web search. Can only veto.
AI_VETO
approved
Paper order placed
Fills at next candle's open + slippage. Charges: STT, brokerage, GST, stamp duty.
Journal + Telegram alert
Every signal, block, veto and fill is logged to journal.csv.
↻ repeats for each stock on every new candle
Kill switch
Daily loss ≥ 3% or STOP file → close all, no new trades.
15:15 square-off
All intraday positions closed. No overnight intraday risk.
market closes 15:30

3 · After market evening

Day report
Trades, P&L after charges, blocks, vetoes. Telegram summary.
Journal review
Claude finds patterns and suggests one change to test.
Backtest the change
Time machine replays past data with the same agents. Adopt only if it holds up after charges.
↻ improved config feeds tomorrow's run
